## 👋 Sobre mim

Sou estudante de **Ciência de Dados e Machine Learning no UniCEUB**. Tenho interesse em explorar dados, encontrar padrões e transformar análises em informações úteis para apoiar decisões.

Estou construindo meu portfólio com projetos práticos em Python. No meu projeto atual, trabalhei com um conjunto de dados de jogos da Steam: organizei e limpei os dados e documentei uma análise exploratória em Jupyter Notebook. Agora, estou aprendendo **Power BI** para levar os resultados para um dashboard.
